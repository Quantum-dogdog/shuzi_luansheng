## 2. 平面气浮台-卫星姿控仿真
气浮台是卫星姿态控制最常用的地面仿真手段：台体托在气膜上，水平方向几乎无摩擦，姿态动力学接近在轨失重状态。本仿真在桌面级气浮台场景中，重点呈现执行机构的真实限制。
### 2.1 物理模型与关键参数
| 量 | 取值 | 说明 |
|---|---|---|
| 台体质量 m | 12 kg | 含气瓶 / 电池 / 电子学 |
| 台体边长 a | 0.45 m | 方板 |
| 转动惯量 I | 0.405 kg·m² | I = m·a²/6 |
| 冷气推力 | 0.2 N × 8 | 平移成对 0.4 N，转向成对 0.078 N·m |
| 平移加速度 | 33.3 mm/s² | 1 s 单只 Δv ≈ 17 mm/s |
| 转向角加速度 | 11.0 °/s² | 0.078/0.405 |
| 最小冲量 | 0.0104 N·s | 50 ms 指令，单只脉冲 Δv ≈ 0.87 mm/s |
| 反作用轮 Iw | 0.0004 kg·m² | Ø112 mm 轮缘集中 |
| 轮速上限 | 6000 rpm | 角动量上限 0.25 N·m·s ≈ 台体 36 °/s |
| 电机力矩 | 0.10 N·m | 满压约 2.5 s 到饱和 |
| 冷气 | 400 g N₂ / 30 MPa | 两级调压到 0.6 MPa |
| 阀门响应 | 开 8 ms / 关 12 ms | 一阶等效 |
| 静/动摩擦 | μs 0.035 / μk 0.028 | 断气后接管 |
| 积分 | 240 Hz | 控制程序 20 Hz 回调 |
**人为夸张**（源码内声明）：真实气膜间隙 5–10 μm，场景显示为 12 mm（放大约 1000×），否则肉眼不可见；气膜流动、均压腔供气、台下管路做"工程示意"，非流场解。
**坠落模型**：质心越过台边（x ±1.60 m / z ±1.20 m）后按绕台边的重力矩 m·g·h·sinθ 积分，转至约 77° 脱离台边、转入自由落体，落地按平板最低点钳制。不建模靶杆 / 气瓶的折断。
### 2.2 四种工作模式
| 模式 | 物理重点 | 建议操作 |
|---|---|---|
| 自由漂移 | 无摩擦刚体手感 | "扰动踢一脚"后观察匀速平移+自转，不加修正 |
| 动量守恒 | 角动量在台体与轮子之间交换 | 只按"轮加速"，台体反向转；轮饱和后停止 |
| 姿态打靶 | 定点指向考核 | 用推力器/轮子把台体指到目标角并稳住 |
| 质心配平 | 质心偏差 → 平移/转动耦合 | 两轴滑杆修偏心至 ≤ 1.0 mm/轴，再"偏航耦合测试"复测 |
### 2.3 姿态打靶计分
捕获条件：末端指向误差 ≤ 1.5°，且 |ω| ≤ 0.8 °/s，保持 1.2 s。
得分 = max(0, round(100 − 2.0×|末端误差|° − 3.0×冷气 g − 0.6×用时 s − 0.3×轮转圈数))
等级：S ≥ 85，A ≥ 70，B ≥ 55，其余 C
以 90° 机动为例：纯推力器约 3.6 g、5.7 s ≈ 85 分；纯轮子约 50 圈、5.0 s ≈ 81 分。小角度轮子略优，大角度推力器明显省分——评分引导就是为了让使用者撞上这个权衡。
### 2.4 星敏感器与星模拟器
台体边装一台窄视场星敏感器，对星模拟屏真成像：独立 `PerspectiveCamera`（14°×18.6° 视场、384×288）仅开 layer 1，渲染到 `WebGLRenderTarget` 后用 `readRenderTargetPixels` 回读，做阈值 + 连通域质心提取。星图窗口中没有任何"画上去的星点"。
| 项目 | 取值 |
|---|---|
| 视场 | 14° (V) × 18.6° (H) |
| 分辨率 | 384 × 288，8 bit 灰度 |
| 星模拟屏 | 0.52 × 0.40 m，距台 ≈ 3.4 m |
| 星点 | 18 颗（北斗七星 + 11 颗暗星），按亮度分级 |
| 提取 | 阈值 118 DN，4 邻域连通域，质心 + PCA 主轴 |
| 输出 | 星数、像面质心、主轴角、视轴偏差（°） |
| 刷新 | "拍照"单帧；"实时"约 5 Hz |
已回归验证：初始姿态下 18 星全在视场，视轴偏差 0.12°；偏航转 5° 像面移 5.00°（星模 3.4 m 外近似无穷远，接近 1:1）；平移 0.15 m 像面移 1.5–2.2°；转 20° 完全失锁 0 星；关星模同一帧即变 0 星并标 `NO STAR`。
### 2.5 控制程序接口与内置示例
侧栏编辑器每 50 ms 调用一次用户函数，返回四个执行机构指令：
// fx / fz 机体系平移指令，tq 转向力矩，rw 反作用轮电机：范围 −1…1
// x, z 单位 m，psi 单位 rad
return { fx: 0, fz: 0, tq: 0, rw: 0 };
反作用轮只施加纯力偶，不产生净力；轮速饱和后电机力矩自动归零。返回非数值或抛异常会自动停机并显示报错，不会静默出结果。状态需要保存时挂在 `window` 上，复位自动清零。
内置 12 个示例，覆盖 PD / PID / 滑模 / bang-bang 时间最优 / 扰动观测器 / 轮卸载。其中方框 / 圆形 / 8 字巡航是**刻意做不到**的例子——需 0.35 m/s² 而实际只有 0.033 m/s²，轨迹被拉成大弧线；气浮台适合验姿态、不适合验平移快速性，示例就是要展示这个边界。
### 2.6 已知简化
- 平移只做水平 2 自由度 + 偏航，不含俯仰/滚转（气浮台的正常工作状态就是"不翻"，翻了即坠落）；
- 推力器无上升/下降沿细节，用 8/12 ms 一阶等效；
- 星敏只做"成像 + 质心提取"，无星图识别、无 QUEST 解算，"视轴偏差"是相对星模拟屏几何中心的偏差，不是惯性姿态；星点用发光球 + Sprite 光晕近似，无 PSF、弥散斑和暗电流噪声；
- 不建模靶杆、气瓶在坠落撞击中的折断与二次弹跳。
## 3. 液氧甲烷发动机试车台
一台 700 kN 级、燃气发生器（开式）循环的液氧甲烷发动机试车台，连同储罐区（+6.0 m 高台）、泵前管路、脐带断开面、试车台架与机柜一并建模，中心为可操作发动机。不是播放式动画，而是一整套可完整执行试车流程与故障诊断的环境。
### 3.1 发动机参数（额定 / 稳态）
| 项目 | 取值 | 说明 |
|---|---|---|
| 推进剂 / 循环 | LOX / CH4 · 燃气发生器（开式） | GG 燃气做功后直接排出，不进主室补燃 |
| 海平面推力 | 700 kN 级，稳态 ≈ 735 kN | 随室压与混合比小幅浮动 |
| 室压 p_c | 15.0 MPa 设定，稳态 15.4–15.5 | 红线 1.15× = 17.25 MPa，持续 0.45 s 跳闸 |
| 混合比 O/F | 2.6 设计，≈ 2.75 稳态 | c* 峰值在 3.2，设计点故意偏富燃 |
| 主流量 | LOX 179.0 / CH4 65.2 kg/s | 主级合计 ≈ 244.2 kg/s |
| 发生器流量 | ≈ 11.6 kg/s | 占总流量 ≈ 4.5%，富燃 O/F ≈ 0.43，燃气 1120 K |
| 喉部面积 A_t | 0.028566 m² | 喉径 ≈ 191 mm |
| 面积比 ε | 8.0 | 一维等熵反解 M_e ≈ 3.12 |
| 出口压力 p_e | ≈ 261 kPa | 海平面欠膨胀，马赫环明显 |
| 推力系数 C_f | 1.661 | 动量项 1.578 + 压力项 ≈ 0.083 |
| 特征速度 c* | 1812 m/s | c* = 1830·exp[−ln²(O/F÷3.2)/(2×1.1²)] |
| 比冲 | 室 307 s / 整机 294 s / 真空 ≈ 317 s | Isp = F/(ṁ·g₀)，按总流量分母 |
| 涡轮泵转速 | 30 000 rpm 额定，≈ 27 800 稳态 | 112% 为数值保护上限 |
| 再生冷却 | 甲烷冷却，壁温 ≈ 860 °C | 热流按 Bartz 标度 ≈ 9.7 MW；壁温红线 1050 °C |
**整机比冲比室比冲低 13 s** 的原因：GG 那 4.5% 的流量只做到涡轮功就排出，不产生推力——这是开式循环的结构性代价。
### 3.2 27 路传感器
按五组布置：
- 液氧侧 8：PT-101/103/104、TT-101/103、FT-101、DP-401、NF-401
- 甲烷侧 8：同构
- 发动机 4：PT-201 室压、TT-201 壁温、TT-202 冷却出口、LT-401 推力
- 涡轮泵 / 发生器 5：PT-202、TT-203 燃气温度、TT-204 排气温度、FT-103、NT-301 转速
- 增压 / 吹除氮气 2：PT-301、PT-302
每路带量程、分辨率、噪声、零点漂移与取整规则，取整规则与仪表显示一致。**点任意通道即可对它注入冻结 / 漂移 / 死值**——故障判读关即基于此。
### 3.3 自动时序与完成判据
9 步时序按真实试车顺序排列：`充装 → 氮气吹除 → 增压 → 点火 → 启动 → 稳态 → 关机 → 后吹除 → 复位`，另有 `紧急关机` 与 `一键顺序` 自动跑完。
一键顺序**不是按固定秒数往下走**：每步写一条可判读的完成条件（取自模型与压力 / 温度 / 累计流量通道），`tick()` 每帧检查，条件成立并保持一小段确认时间才转下一步。超时不静默跳过——停在原步，把实测值写进试车记录，状态栏显示"自动时序中断"。整轮约 70–80 s，其中预冷最长。
| # | 步骤 | 完成判据（实测） | 典型耗时 |
|---|---|---|---|
| 1 | 充装 | 两箱充装率 ≥ 99.5% | 满箱 ~1 s；补装约 50 s/箱 |
| 2 | 氮气吹除 | PT-301 ≥ 10 MPa 且累计吹除 ≥ 20 kg | ~6 s |
| 3 | 增压 · 预冷 | PT-101/102 ≥ 0.60 MPa，TT-103 ≤ −150 °C，TT-104 ≤ −100 °C | ~28 s |
| 4 | 点火 | 火炬建立稳定火焰 | ~1.2 s |
| 5 | 启动建压 | 主室燃烧且 Pc ≥ 14.2 MPa | ~4 s |
| 6 | 稳态试车 | 连续 20 s；红线 / 熄火 / 主级丢失立即中止 | 20 s |
| 7 | 关机 | 推力 < 3 kN 且 Pc < 0.25 MPa | ~3 s |
| 8 | 后吹除 | 本步累计吹除 ≥ 30 kg | ~8 s |
| 9 | 隔离 · 关阀 | 气源关断、PT-301 < 1 MPa、主室余压 < 0.10 MPa | ~1.5 s |
稳态是唯一天然的"定时"步骤：试车时长由任务书给定，不是等某个传感器。其它每一步都在等物理量到位。预冷/充填期间，泵后未汽化的过冷推进剂经**预冷回液阀**送回罐内气枕——既带走管路热量，又避免憋出气塞，这是真实低温试车系统的必配段。
### 3.4 阀门与手动控制
共 11 个阀门：液氧/甲烷 预充阀、主阀（可调开度）、发生器阀、贮箱增压阀、氮气调压阀、燃烧室吹除阀、液氧/甲烷 预冷回液阀。每个都带一阶开闭动态与联锁条件。
- 推力级：0–100% 滑杆（步进 1%）。GG 循环靠泵转速节流：主阀保持设计开度，由发生器阀按室压闭环匹配涡轮功率。
- 混合比微调：−15% … +15%，主阀开度 = 推力级 × (1 + 微调)。
- 任何手动干预都会退出自动时序，避免两个指令互相打架。
### 3.5 故障注入与保护联锁
10 类硬件故障 + 3 种传感器故障，每个都是 0→1 的 `sev` 斜坡，效应量 = f(sev)，注入与清除都是**渐变 + 耦合**，沿"增压 → 入口 → 泵 → 流量 → 室压 → 推力 → 红线"向下游连锁：
| 故障 | 现象与连锁 |
|---|---|
| 火花塞失效 | 火炬点不着 → 主室不点火 |
| 发生器点火失效 | GG 不点火 → 涡轮无功率 → 泵不建压 |
| 氧 / 甲烷喷注器堵塞 | 对应侧流量掉 → O/F 偏移，室压与推力下降 |
| 主氧阀卡滞 | 阀位冻结，指令无效 |
| 主甲烷阀泄漏 | 关阀后仍内漏，关机后室压缓降不干净 |
| 涡轮泵轴承故障 | 效率下降 + 轴系振动抬升 → 同转速压升不足 |
| 泵入口汽蚀 | NPSH 余量跌破 100%，流量喘振式波动 |
| 氧箱增压失效 | 箱压衰减 → NPSH 被抽掉 → 诱发汽蚀（根因是增压） |
| 冷却通道堵塞 | 换热系数下降 → 壁温飞升，流量与室压看似正常 |
| 传感器故障 | 单通道冻结 / 漂移 / 死值 |
保护与联锁：
- **红线**：室压 > 17.25 MPa 持续 0.45 s → 紧急关机 + 红色横幅，须"复位"才能再起动（延时为躲开 6.3% 起动超调）。
- **壁温红线** 1050 °C；**转速保护** 112% 额定。
- **脐带闭锁**：快接头脱开后两路推进剂被截断，所有时序动作被闭锁并在面板明示原因。
- **汽蚀锁存**：一旦发生过汽蚀，`npshBad` 保持，直到复位。
### 3.6 四关考核
| 关 | 考什么 | 判据 |
|---|---|---|
| 一 · 系统认知 | 5 道选择题：循环形式、红线整定、c* 峰值、NPSHr 标度、高台静压头作用 | 答对即给成绩，附逐题解析 |
| 二 · 系统特性 | 把主级稳在判据带内 | 室压 / 推力 / O/F / 转速 / 壁温五项同时满足并保持 5 s |
| 三 · 故障判读 | 主级稳定后**静默注入**一个未知故障 | 屏蔽 3D 高亮与故障面板，从仪表链判读根因，首判正确 + 执行安全处置 |

### 3.7 已知简化
- **35% 推力档存在节流阀位极限环**（室压 6.25–6.78 MPa、周期约 4 s、±4% 波动）。这是模型的可复现特性而非遥测噪声，故第四关把该档排除在外，这条写在代码注释里。
- 燃烧按理想燃烧 + 一维等熵 + 经验 C_f，不做 CFD、不做燃烧不稳定建模；
- 涡轮泵为集总参数模型（转速一阶 + 效率/汽蚀修正），不含叶片级细节；
- 结构、振动、热应力只做趋势与报警，不做有限元；
- 关机后的剩余推力、吹除置换做"工程示意"级演化；
- **预冷时间常数做了压缩**：真实大口径液氧管路冷透常要数分钟，这里氧侧 τ=10 s（约 30 s 从 +22 °C 到 −150 °C）、甲烷侧 τ=8.5 s。判据、流向和"必须冷透才转点火"的逻辑不变，只压缩了时间尺度。
